# ADR-0001：榫卯 AI 社区使用独立 Git 仓库

- 状态：已接受，服务器切换及公网验收已于 2026-10-13 完成
- 日期：2026-10-13

## 背景

社区最初位于 `instant-ai-finance/services/sunmao-ai-community`。运行时虽然已经拥有独立进程、端口、数据库和域名，但手机云端 Codex 仍会把整个大仓库作为工作环境，容易混入其他系统的上下文，也增加误改风险。

## 决策

把社区代码迁移到 `wangbaocheng123-hash/sunmao-ai-community` 独立仓库。继续与北京博主采集器共用服务器，但保持以下并列边界：

- 社区：`sunmao-ai-community.service`、`127.0.0.1:18808`、`/var/lib/sunmao-community/`
- 采集器：保持自身服务、端口、数据和发布通道不变
- Caddy 只把社区域名代理到社区端口

独立仓库使用 `main` 保存开发状态，使用 `production` 作为显式生产发布分支。

## 迁移策略

1. 先创建和验证独立仓库，不触碰线上服务。
2. 让新仓库 `production` 的代码树与当前线上版本一致。
3. 备份服务器发布状态，切换 Git origin 后做一次可回滚发布。
4. 验证域名、健康检查、版本号、留言数据库和采集器健康状态。
5. 稳定后再从旧大仓库删除重复目录，避免迁移窗口内失去回滚来源。

## 结果

手机云端 Codex 可以只加载社区代码，发布权限和故障边界更清晰；服务器成本、域名和用户数据路径不变。迁移期间会短暂保留两份代码，直到新发布源验证完成。
